# Application Tkinter avec Graphiques

Cette application Python développée en Tkinter permet d’afficher des graphiques et de visualiser des données de manière simple et interactive.

## 🎯 Fonctionnalités
- Interface graphique Tkinter
- Chargement de données simples
- Génération de graphiques (matplotlib)
- Boutons pour lancer les affichages
- Organisation du code en plusieurs fonctions

## 🛠 Technologies utilisées
- **Python 3**
- **Tkinter** (interface graphique)
- **Matplotlib** (graphiques)
- **Pandas** (si tu l’as utilisé pour les données)

## ▶️ Lancer l’application

```bash
python app.py
